# 🧩 Apply Constraint Plugin
## About Plugin
This plugin lets you apply UI constraints:
* UIAspectRatioConstraint
* UISizeConstraint
* UITableLayout
* UIListLayout
* UIGridLayout
* UIPageLayout
* UIPadding
* UIScale

And scale frames from Offset to Scale size
# 📲 How to Install
1. Download .rbxmx file [(About .rbxmx)](https://fileinfo.com/extension/rbxmx)
2. Insert it into the AppData/Local/Roblox/Plugin folder
3. Restart the Roblox Studio if needed
# ✅ How to Use
## Apply
1. Choose one or multiple frame-like instances
2. Click the Apply button

* Descendants of chosen frames will be also used
* Plugin removes constraints and sets frame's AbsolutePosition and AbsoluteSize as its Position and Size

## Scale
1. Choose one or multiple frame-like instances
2. Click the To Scale

* Descendants of chosen frames will NOT be used if they aren't chosen too
* Plugin calculates the Scale size for Position and Size, then sets
